# BusinessUp Hub — Funil Cash Machine Viral

Landing page estática, mobile-first e responsiva para o guia digital **Funil Cash Machine — Viral**.

## Estrutura do projeto

- `index.html` — estrutura, copy e seções da página.
- `styles.css` — identidade visual, responsividade e elementos 3D em CSS.
- `script.js` — animações progressivas sem bloquear a leitura; atualização automática do ano.
- `robots.txt` — regra básica para rastreadores.
- `assets/hero-funnel.webp` — arte 3D principal do funil (1600 × 900).
- `assets/workspace.webp` — fotografia editorial para a seção de identificação das dores (1600 × 900).
- `assets/funnel-detail.webp` — arte complementar de funil para a composição da seção 3D.
- `assets/favicon.svg` — ícone vetorial da marca.

As imagens exibidas pelo site estão em WebP otimizado para manter boa resolução com carregamento leve. O mockup do guia e o funil tridimensional da seção “O método” também têm elementos construídos em HTML/CSS, não dependem de vídeo ou bibliotecas 3D externas.

## Publicar na Vercel

1. Extraia o ZIP.
2. Envie `index.html`, `styles.css`, `script.js`, `robots.txt` e a pasta `assets/` para a raiz do repositório.
3. Importe o repositório na Vercel como projeto estático. Não é necessário framework nem comando de build.
4. Depois de definir o domínio final, configure os metadados/SEO e, se necessário, crie um `sitemap.xml` com esse domínio.
